# Bachelor's Thesis Template

This repository contains a Quarto template for a bachelor's thesis at the School of Business and Economics of Humboldt-Universität zu Berlin used by [Christoph Scheuch](https://christophscheuch.github.io/).

It is based on the following information:

- [Official Guidelines](https://www.wiwi.hu-berlin.de/de/studium/rund-um-das-studium/sb/leitfaden.pdf)
- [Guidelines](https://www.wiwi.hu-berlin.de/en/Professorships/bwl/finance/study/bachelor/bachelor-thesis-in-finance-guidelines-6.pdf) of Beatriz Mariano 

## Important Note

**The content in this template is placeholder text generated by Claude.** This includes:

- The thesis text (abstract, introduction, literature review, data, results, and conclusion)
- All bibliographic references in `references.bib`
- Results generated by R code. 

While the references cite real academic papers with accurate metadata, the specific claims, statistics, and findings described in the thesis text are fabricated for demonstration purposes only.

## Usage

Replace all placeholder content with your own research before submission.

## Files

- `thesis.qmd` — Main Quarto document
- `thesis.pdf` - Rendered PDF output
- `references.bib` — BibTeX bibliography file
